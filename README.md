# Task Automation with Python Scripts

## 📌 Project Overview

This project is part of **CodeAlpha Task 3: Task Automation with Python Scripts**. The goal of this project is to automate a simple real-life repetitive task using Python.

The script automatically identifies all `.jpg` image files from a source folder and moves them into a separate destination folder. This helps organize files and reduces the need for manually moving images.

## 🚀 Features

- Automatically checks the source folder
- Creates the destination folder if it does not exist
- Identifies `.jpg` files
- Moves the selected images automatically
- Displays a success message after moving each file
- Reduces repetitive manual file management

## 🛠️ Technologies Used

- Python
- `os`
- `shutil`
- File Handling
